DSP 核心演算法量測數據驗證與發燒搭配指南

在 rooPlayer 的高傳真數位音訊處理鏈路中，由 取樣率轉換 (SRC) 濾波器、高階 Sigma-Delta 調變器 與 超音波防護濾波器 構成三道堅實防線：
• 第一道防線（SRC 濾波器）：在多相超取樣升頻時精確濾除鏡像反射（Images），杜絕混疊折返。
• 第二道防線（Sigma-Delta 調變器）：透過 5 階（CRFB）或 7 階（CLANS）多回授噪聲整形（Noise Shaping），將單 bit 量化噪聲全面推移至超高頻。
• 第三道防線（超音波防護濾波器）：在類比前級以 2 階巴特沃斯低通濾除超聲高頻能量，保護後級擴大機與高音單元免於射頻互調失真（RF IMD）與過熱。

一、7 種核心取樣率轉換 (SRC) 濾波器原理與實測數據

依照旗艦高階 DSP 架構，由基礎四大正交維度（頻域滾降特性 × 時域相位特性）加上三款發燒級長階線性相位演算法構成：
• 精準 (Precise)：採用 Kaiser 窗多相 FIR（β ≈ 14.47, As ≥ 140 dB），通帶 0~20kHz 零衰減，奈奎斯特截止極度陡峭。
• 平滑 (Smooth)：採用高斯窗 sinc 緩降 FIR，自 18kHz 平緩慢滾降，消除高頻生硬數位感，時域鈴振時長縮短 >55%。
• 線性相位 (Linear Phase)：對稱衝激響應，全頻段群延遲恆定，絕對零相位失真。
• 最小相位 (Minimum Phase)：透過複倒頻譜希爾伯特變換（Spectral Factorization）將零點完全反射至單位圓內，預響鈴嚴格為零 (0.00% Pre-ringing)，符合人耳聽覺心理前向遮蔽效應。
• 高斯長階 (Gauss Long)：仿 HQPlayer poly-sinc-gauss-long，採純高斯窗（σ = 0.17L，邊緣自然衰減 < -150 dB）搭配 449 輸入階多相 Sinc，20 kHz 內零衰減、奈奎斯特 -166.6 dB 深度抑鏡，時域呈平滑高斯包絡無硬切邊。
• poly-sinc-ext2：仿 HQPlayer poly-sinc-ext2，1,281 輸入階超高陡峭 Kaiser 窗（As = 175 dB），通帶延伸至 20.8 kHz 依然 0.000 dB 完全平坦，於 22.05 kHz 瞬間達成 -183.0 dB 磚牆抑鏡。
• sinc-M：仿 HQPlayer sinc-M / Chord M-Scaler，採 Partitioned FFT 分段多相卷積（立體聲複數打包 L+iR 2 倍加速），每相 65,535 階（16x 升頻總原型達 1,048,545 taps），44.1 kHz 下平坦延伸至 21.95 kHz、22.15 kHz 第一鏡像直壓 -205.3 dB，1 kHz 重建 SNR 達 242.5 dB，且 4x 1 秒立體聲僅耗時 17.0 ms（~59x 即時速度）。

二、DSD 5 階 / 7 階與 ASDM5EC / ASDM7EC 調變器量測驗證

rooPlayer 內建純 64 位元浮點 Sigma-Delta 調變器。透過實機生成 -6dBFS 同調 1kHz 正弦波進行 262,144 點 7-term 週期型 Blackman-Harris FFT（旁瓣 < -180 dB）頻譜分析與位元級 Hamming 距離驗證：
• 5 階 (CRFB)：級聯共振回授架構（H∞ = 1.55），高頻噪聲抬升適度，類比氛圍感強烈，CPU 佔用極低。
• 7 階 (CLANS)：閉迴路局部反饋噪聲整形（H∞ = 1.50），NTF 噪聲整形斜率高達 52.6 dB/oct，可聽頻帶內背景極致純黑寧靜。
• ASDM5EC（5 階高 H∞ Trellis 強化修正）：仿 HQPlayer ASDM5EC 原理，採用專屬高增益 5 階 NTF（H∞ = 1.85）搭配 M=4 路徑、32 步回溯深度的狀態機 M-Algorithm Trellis（含祖先一致性剪枝），在 DSD64/128/256 全規格將可聽帶 SNR 穩定拉高 +13.3 ～ +14.1 dB、THD 壓低 -14.4 ～ -17.5 dB、超聲噪聲再降 -11.8 ～ -14.0 dB，且 0 dBFS 滿度輸入仍完全穩定。
• ASDM7EC（7 階高 H∞ Trellis 強化修正）：仿 HQPlayer ASDM7EC 原理，採用專屬高增益 7 階 NTF（H∞ = 1.75）搭配 AVX2+FMA 四路平行 M=4 / L=32 狀態機 Trellis，DSD64 帶內 SNR 暴增 +19.55 dB（達 154.99 dB）、DSD128 暴增 +20.86 dB（達 201.16 dB）、超聲噪聲（20k–50kHz）全面再降 -17.6 ～ -19.6 dB，同時將高階積分器峰值偏移壓低 50% ～ 82%，DSD256 仍達 2.3x 即時速度（DSD64 / DSD128 / DSD256 皆可流暢播放）。

四、量化抖動 (Quantization Dither) 演算法原理與實測驗證

在數位音訊處理中，由 64 位元浮點數轉化為 24 位元 / 16 位元 PCM 整數，或進入 1 位元 Delta-Sigma DSD 調變器時，必須進行「字長縮減 (Wordlength Reduction)」。 若直接捨入或截斷（Truncation），量化誤差將與音訊訊號高度相關，在微弱樂音、殘響消散與空間泛音尾端退化為方波階梯，產生高達 20%~30% 的奇次諧波失真與粗糙刺耳的量化底噪（Quantization Distortion）。 根據 Lipshitz & Vanderkooy 定理，注入適當機率密度函數（PDF）的抖動訊號，能將量化誤差的一階矩與二階矩與訊號完全解耦，將失真徹底轉化為平坦或形狀可控的良性背景白噪聲：
• TPDF (標準三角形分佈)：由兩個獨立均勻隨機變數相減構成（2 LSB 峰值）。誤差相關係數 $r \to 0.000$，諧波失真降低超過 17 dB，為錄音室無失真絕對線性基準。
• HP-TPDF (高頻加權三角形)：經過 $H(z) = 1 - z^{-1}$ 一階高通差分濾波，將抖動能量向超高頻推移，人耳最敏感的 1kHz~4kHz 頻段底噪降低 4.27 dB。
• Noise-Shaped (人耳等響度噪聲整形)：採用 3 階等響度誤差回授濾波器，在人耳最敏感的 3.5kHz~4kHz 凹槽深度整形，主觀敏感帶底噪大幅壓降 14.87 dB，背景呈現極致漆黑深邃。
• Gauss (高斯溫潤分佈)：Box-Muller 連續無界常態分佈，具備無限長平滑高斯尾端，是徹底打散高階 Delta-Sigma (DSD) 內部積分器極限環（Limit Cycles）與直流閒置單音（Idle Tones）的最佳聲學方案。

五、發燒最佳全鏈路聲音搭配指南 (Acoustic Matching Guide)

  • 最高保真監聽組合 (旗艦推薦預設)：精準，線性相位 ➔ 7 階 (CLANS) ➔ TPDF 或 Gauss ➔ DSD128 / DSD256 ➔ 30k / 40k。全頻段絕對零相位失真，阻帶衰減 >140dB，背景深黑漆黑，音場定位如刀刻清晰，最忠實呈現交響樂、大編制與母帶細節。
  • 極致漆黑背景與微弱細節挖掘：精準，線性相位 ➔ 4x / 8x PCM ➔ Noise-Shaped 抖動 ➔ 30k / 40k。3 階人耳等響度噪聲整形將人耳最敏感頻段底噪大幅深挖至 -114 dBFS，錄音室微弱殘響、空間空氣感與樂器消散尾音纖毫畢現。
  • 節奏律動與打擊樂瞬態衝擊組合：精準，最小相位 ➔ 7 階 (CLANS) ➔ HP-TPDF 抖動 ➔ DSD128 ➔ 30k。嚴格零預響鈴讓能量集中於脈衝最初瞬間，爵士鼓點與低頻下潛凝聚結實，速度感、爆發力與動態張力極致凌厲。
  • 溫潤發燒人聲與弦樂重奏組合：平滑，線性相位 ➔ 5 階 (CRFB) ➔ Gauss 高斯抖動 ➔ DSD128 / DSD256 ➔ 30k。高斯抖動徹底消除 Delta-Sigma 極限環，時域鈴振時長大幅縮短 75%，泛音溫暖厚實自然，消除高頻冷硬毛刺，人聲甜美滑順、久聽不累。
  • 發燒黑膠老類比韻味組合：平滑，最小相位 ➔ 5 階 (CRFB) ➔ Gauss 高斯抖動 ➔ DSD64 / DSD128 ➔ 20k / 30k。零預響鈴加上超短後響鈴，完全消除數位硬邊，重現經典黑膠唱片與早期 SACD 迷人的溫潤厚重感。
  • 純 PCM 超取樣直通組合：精準，線性相位 ➔ 4x 整數倍頻 (176.4k / 192k) ➔ TPDF 抖動 ➔ 關閉 (None) / 30k。純 PCM 多相 FIR 超取樣直出，線性無失真量化抖動，由 DAC 本地解碼，細節通透開闊。
  • HQPlayer 風格全能發燒組合 (Gauss Long + ASDM7EC)：高斯長階，線性相位 ➔ ASDM7EC ➔ Gauss 高斯抖動 ➔ DSD128 / DSD256 ➔ 30k / 40k。純高斯包絡搭配高 H∞ 7 階 M=4 / L=32 Trellis 強化修正，兼具 20kHz 內零衰減、超低底噪（+20 dB SNR 提升）與寬鬆立體音場。
  • 高線性溫潤平衡組合 (Ext2 + ASDM5EC)：poly-sinc-ext2，線性相位 ➔ ASDM5EC ➔ Gauss 高斯抖動 ➔ DSD128 / DSD256 ➔ 40k / 關閉。DSD128 帶內 SNR 達 150.5 dB、超聲噪聲更低且 CPU 負載輕盈，人聲與微細節透明自然。
  • 百萬階 M-Scaler 終極空間解析組合 (Sinc-M)：sinc-M，線性相位 ➔ 8x / 16x 整數倍 PCM 或 DSD256 ➔ Noise-Shaped / Gauss ➔ 關閉 / 40k。Partitioned FFT 百萬階多相卷積提供 242dB 重建精度與 22kHz 垂直刀切抑鏡，重現現場廳堂深度與針點結像。
