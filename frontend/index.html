各選單功能與操作手冊

rooPlayer 採用高效能 Rust + Tauri v2 原生架構，將本地無損音樂收藏與先進 rooDSP 處理器、WASAPI 獨佔輸出、DLNA 串流設備深度融合。以下為各功能模組精簡說明：

介面語言與自適應視窗：右上角可隨時切換「繁體中文 / English」與「深色 / 淺色」主題。軟體邊界具備 840 × 680 最小尺寸保護，縮小至極限時按鈕與各欄位自動適應不重疊。

總覽

首頁總覽 (Overview)

音樂庫核心儀表板，整合本地與線上串流數據：

  • 曲庫統計：即時統計專輯數、曲目數與 Hi-Res 無損格式分佈。
  • 最近播放：自動記錄近期播放專輯，支援一鍵即時續播。
  • 每日推薦與藝人誌：依聆聽喜好每日精選發燒代表作，深入探索大師生平名盤。
曲庫瀏覽

專輯、演出者與曲目 (Library)

多維度曲庫檢視與自訂配置：

  • 排序方式：支援依新增時間、專輯名稱 A-Z、演出者、年份及播放次數排列。
  • 封面縮放：提供小、中、大三段尺寸切換，各頁面獨立記憶。
  • 純淨元資料：清楚展示演出者、廠牌、年份與曲目資訊，介面簡潔無干擾。
收藏管理

我的最愛 (Favorites)

個人發燒精選收藏庫：

  • 一鍵收藏：點擊任何專輯、曲目或演出者卡片上的愛心圖示 (♡) 快速加入收藏。
  • 快速播放：支援「播放全部最愛」與「隨機播放最愛」捷徑。
  • 備份遷移：收藏清單支援完整匯出與智慧去重匯入。
播放清單

播放清單 (Playlists)

自由組織與編輯曲目播放順序：

  • 儲存與建立：播放隊列可直接一鍵儲存為命名清單，或手動建立空白清單。
  • 清單編輯：支援單曲上下移動排序、單曲移除與清單重新命名。
  • 匯入匯出：支援標準 .m3u / .m3u8 / .json 檔案，跨播放器輕鬆遷移。
Hi-Res 串流

TIDAL 串流探索中心 (TIDAL Hi-Res)

直連 TIDAL 百萬母帶級 Hi-Res MAX 無損串流：

  • 發燒推薦：分類晶片一鍵篩選發燒名盤、女聲、古典交響、爵士與流行。
  • 同步發行與合輯：即時更新全球高動態新發行與官方評測合輯。
  • 雲端同步與整合：登入個人帳號同步收藏，線上專輯可一鍵加入本地曲庫共同管理。
線上串流

KKBOX 串流中心 (KKBOX Streaming)

直覺接軌華語及全球流行曲庫：

  • 即時排行榜：探索華語、西洋、日韓、搖滾、爵士與古典等多語系即時榜單。
  • 精選與新歌：掌握潮流新歌速爆與官方情境精選歌單。
  • 整榜播放與搜尋：支援全榜一鍵播放、加入佇列與百萬線上曲目即時搜尋。
儲存與維護

本機儲存與資料庫管理 (Storage)

管理本地音樂目錄與資料庫備份：

  • 快速掃描：批次高速剖析本機 FLAC / WAV / DSF / DFF 音訊標籤與封面。
  • 唯讀保護：以唯讀方式掃描硬碟，絕不修改或刪除實體音樂檔案。
  • 備份與還原：支援將曲庫、最愛與播放次數匯出為 JSON，匯入時自動去重。
專屬 DSP 處理器

專屬 rooDSP 處理器 (rooDSP Processor)

全頁面專業數位訊號處理環境（旗艦 MUSE 風格），支援整套預設值管理：

  • 動態範圍餘量管理 (Headroom)：設定 0 至 -24dB 預降增益，防範等化器與升頻運算削頂（Clipping），附削頂指示器。
  • 取樣率轉換 (SRC)：
    • PCM 升頻：支援 2x / 4x 整數倍頻升頻與多階 FIR 相位（純真還原、線性相位、最小相位、高斯、PS-EXT2 等，止帶衰減最深達 -180dB）。
    • 1-bit DSD 調變：內建 2 / 5 / 7 階諧振噪聲整形 Delta-Sigma 調變器，支援即時調變至 DSD64 ~ DSD512。
  • Crossfeed (耳機互饋)：降低耳機頭中效應，重建前方自然立體音場。
  • 參數等化器 (PEQ)：多頻段互動式頻率曲線拖曳，支援低架/峰值/高架/低通/高通/陷波濾波，並內建 6 組命名預設槽。
  • 卷積濾波器 (IR)：載入空間校正或耳機校準 WAV 脈衝響應檔，64-bit 浮點分割式頻域高精度運算。
  • 超音波保護：內建 30k / 50k 高頻安全防護，隔絕超高頻干擾，保護後級擴大機與高音單體。
輸出與訊號路徑

音訊輸出端點與訊號路徑 (Signal Path & Audio Zones)

發燒級位元完美輸出與網路推播：

  • 訊號路徑 (Signal Path)：點擊底欄紫色狀態燈即時彈出路徑卡片，透明呈現「來源 ➔ 解碼 ➔ DSP ➔ 端點」階段，清晰標示位元完美 (Bit-Perfect) 狀態。
  • WASAPI Exclusive 獨佔模式：繞過 Windows 系統混音器，專用音訊執行緒直通 USB DAC，保障純淨位元無損。
  • DLNA / UPnP 網路推播：自動探索或直接指定 IP 連線區網串流播放機（Eversolo、WiIM、Linn 等），支援無損 PCM 與 DSF 原生直通。
  • 漸進式串流推送：多核心平行邊轉邊推，開播即刻響起，切換曲目即時清空緩衝，不延遲、不卡頓。
智慧檢索

全域即時搜尋 (Global Search)

頂部搜尋列支援毫秒級即時跨庫檢索：

  • 跨庫聯合檢索：同步搜尋本機曲庫與線上串流（TIDAL / KKBOX）百萬音軌。
  • 分類快速聚焦：支援依「全部」、「本機專輯」與「線上串流」標籤精準過濾。
播放體驗

播放控制、全螢幕頻譜與自適應介面 (Player & UI)

沉浸式發燒操作介面與視窗防護：

  • 發燒底欄控制器：支援隨機、單曲/全部循環、音量衰減與 Hi-Res 格式即時徽章（如 24/96 FLAC）。

DSP 核心演算法量測數據驗證與發燒搭配指南

在 rooPlayer 的高傳真數位音訊處理鏈路中，由 取樣率轉換 (SRC) 濾波器、高階 Sigma-Delta 調變器 與 超音波防護濾波器 構成三道堅實防線：
• 第一道防線（SRC 濾波器）：在多相超取樣升頻時精確濾除鏡像反射（Images），杜絕混疊折返。
• 第二道防線（Sigma-Delta 調變器）：透過 5 階（CRFB）或 7 階（CLANS）多回授噪聲整形（Noise Shaping），將單 bit 量化噪聲全面推移至超高頻。
• 第三道防線（超音波防護濾波器）：在類比前級以 2 階巴特沃斯低通濾除超聲高頻能量，保護後級擴大機與高音單元免於射頻互調失真（RF IMD）與過熱。

一、4 種核心取樣率轉換 (SRC) 濾波器原理與實測數據

依照旗艦高階 DSP 架構，由兩大正交維度（頻域滾降特性 $\times$ 時域相位特性）組合而成：
• 精準 (Precise)：採用 Kaiser 窗多相 FIR（$\beta \approx 14.47, A_s \ge 140\text{ dB}$），通帶 0~20kHz 零衰減，奈奎斯特截止極度陡峭。
• 平滑 (Smooth)：採用高斯窗 sinc 緩降 FIR，自 18kHz 平緩慢滾降，消除高頻生硬數位感，時域鈴振時長縮短 >75%。
• 線性相位 (Linear Phase)：對稱衝激響應，全頻段群延遲恆定，絕對零相位失真。
• 最小相位 (Minimum Phase)：透過複倒頻譜希爾伯特變換（Spectral Factorization）將零點完全反射至單位圓內，預響鈴嚴格為零 (0.00% Pre-ringing)，符合人耳聽覺心理前向遮蔽效應。
